# Self-hosted fonts

These files are served directly by the static site. No runtime CDN is required.

| File | Family | Supported weight | Size |
| --- | --- | --- | --- |
| `bebas-neue-latin.woff2` | Bebas Neue | 400 | 13,768 bytes |
| `space-grotesk-latin-variable.woff2` | Space Grotesk | Variable, 300–700 | 22,288 bytes |

Both fonts are licensed under the SIL Open Font License 1.1. The complete licenses are included as `Bebas-Neue-OFL.txt` and `Space-Grotesk-OFL.txt` and should remain alongside the font files when distributed.

These are the Latin WOFF2 subsets supplied by Google Fonts, downloaded September 28, 2026. Other writing systems will use the CSS system-font fallback unless additional subsets are added.

Sources:

- https://fonts.google.com/specimen/Bebas+Neue
- https://fonts.google.com/specimen/Space+Grotesk
- https://github.com/google/fonts/tree/main/ofl/bebasneue
- https://github.com/google/fonts/tree/main/ofl/spacegrotesk
