# Local reference study copies

These WebP images are optimized study copies of the user-supplied files in `examples/`. They preserve the originals and make local visual review quicker.

They are design references only. They are not website assets and must not be included in the public Apache upload. No rights to reproduce the recognizable reference artwork are implied.

Each image was resized to fit within 1000 × 1000 pixels without enlargement, stripped of metadata, and saved as WebP at quality 82. The original files remain unchanged in `examples/`.
